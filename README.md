# Salesforceレポートダウンローダー

Salesforce のレポートをまとめて落とし、**使う側のプロジェクトが読みに行くフォルダへ直接置く**ツール。

```
レポート一覧.csv（何を・どこへ）
        ↓
    Salesforce ──→ \\server\案件集計\input\案件一覧_20260814.csv
                   \\server\売上帳票\input\売上_20260814.csv
                        ↑
                   取得が失敗した日は、人がここへ同じ名前で置く
```

共通ライブラリ [comken](https://github.com/tenniscorecom/original_libs) を使っています。

## 何をするか

- 管理表（`レポート一覧.csv`）に書いたレポートを順に落として、**行ごとの置き場所**へ `名前_日付.csv` で保存する
- **落とすものが増えても、コードは触らない。** 管理表に1行足すだけ
- 接続する組織は**レポート URL のドメインから決まる**ので、組織を選ぶ列は無い

## 使い方

### 1. 準備（初回だけ）

```bat
:: Salesforce の client_id / client_secret を登録する（画面が開きます）
認証情報の登録.bat
```

`レポート一覧.csv.example` を `レポート一覧.csv` にコピーして、実際のレポートを書きます。

| 列 | 中身 |
|---|---|
| 名前 | 置くファイルの名前（`案件一覧` → `案件一覧_20260814.csv`）。**使う側はこの名前で探す** |
| レポートURL | Salesforce でレポートを開いたときのアドレスを**そのまま貼る**。ID だけを抜き出す工程で写し間違いが起きるため |
| 置き場所 | 使う側のプロジェクトが読みに行くフォルダ |

同じレポートを2つのプロジェクトが使うときは、**行を2つ書いて2回落とします**。

### 2. 実行

`実行.bat` をダブルクリック（または `python main.py`）。

## 動きで決めてあること

1. **すでに今日の分が置いてあれば取りに行かない。** 落とし直しを省くためだけでなく、**人が手で置いたファイルを上書きしないため**。失敗した分を手で置いて再実行すれば、残りだけを取りに行きます
2. **1件失敗しても残りは続ける。** 5本のうち1本が落ちたときに全部やり直すと、手で用意する手間が5本ぶんになります
3. **0 行は成功にしない。** 空の CSV を置くと、使う側は「データが無い日」と「取得が失敗した日」を区別できません
4. **置き場所のフォルダが無ければ、作らずに失敗させる。** 無いのは書き間違いのことが多く、勝手に作ると誰も読まない場所へ置き続けます
5. **失敗があれば最後に例外で止める。** ログだけ出して正常終了すると、RPA 基盤から見て成功と区別が付きません

## 使う側（読む側）の書き方

置き場所を自分の input にしておけば、読むのは1行です。

```python
from comken.utils.files import FileFinder

path = FileFinder(INPUT_FOLDER).today("案件一覧*.csv")  # 無ければ FileNotFoundError
rows = CsvReader(path).read_rows()
```

## 置いていないもの

- **config.ini** — 変えるのは管理表の中身であって、管理表の場所ではないので要りません
- **受け渡し用の中間フォルダ** — 置き場所に使う側のフォルダを直接書けば済みます

## 注意

- 実物の `レポート一覧.csv` は**組織名・レポート ID・社内のフォルダ構成が入る**ため、git に含めません（`.gitignore` 済み）。リポジトリに置くのは `レポート一覧.csv.example` だけです
- 認証情報は Windows の DPAPI で暗号化され、**登録した Windows ユーザー・その PC でしか復号できません**。タスクスケジューラで動かす場合は、実行アカウントで登録してください
